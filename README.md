# Final Project - Home Greeting System with Face Recognition

[English](README.md) | [Tiếng Việt](README.vn.md)

## Description

A greeting system that trains a model to recognize faces through TensorFlow and Keras. An ESP32 controller will then be used to call on a python backend to display the name of a recognized face on the frontend kiosk.

## Tech Stack

- Python
- TensorFlow
- Keras
- ESP32
- FastAPI (Backend)
- React (Vite) (Frontend)

## How to Run

1. First, clone the repository and navigate to the backend directory:

```bash
git clone
```

2. Install the required dependencies for the backend:

```bash
cd backend
pip install -r requirements.txt
```

Optionally, you can install the dependencies through the `uv` package manager:

```bash
uv sync
```

3. Gather the dataset by following the prompts by running:


```bash
python backend/scripts/01a_collect_faces.py
```

The data will then be stored in the `backend/dataset` directory, with the training data in `backend/dataset/train` and the validation data in `backend/dataset/value`.


4. Train the model using the provided training script. You may use any of the models found in the `backend/scripts/training` directory. For example, to train the model using the EfficientNetV2B0 backbone, run:

```bash
python scripts/02_train_model_2.ipynb
```

Take note that for `02_train_dense.ipynb`, you will need to have the `train_landmarks.csv` and `val_landmarks.csv` files in the `backend/dataset` directory, which can be generated by running the `01b_extract_landmarks.py` script.

5. After training, the model will be saved in the `backend/models` directory. You can then start the backend server:

```bash
uv run backend/app/main.py
```

You may change what keras file to use by changing the `MODEL_PATH` variable in `backend/app/main.py`.

6. Finally, start the frontend server:

```bash
cd frontend
npm install
npm run dev
```

You may also use `bun` instead of `npm` if you have it installed:

```bash
cd frontend
bun install
bun run dev
```

7. The frontend should now be running at `http://localhost:5173`. You can test the face recognition by sending a POST request to the backend by showing your face to the camera through the frontend interface. If the face is recognized, the name of the person will be displayed on the frontend kiosk, and will also be seen on the ESP32's serial monitor.

## Specifications

- The model should be trained on a dataset of faces, with at least 5 different classes (people).
- The model should achieve at least 80% accuracy on the validation set.
- The backend should be able to receive a POST request with an image, and return the predicted class (name of the person) in the image.
- The frontend should be able to display the name of the recognized person when a face is detected through the camera.
